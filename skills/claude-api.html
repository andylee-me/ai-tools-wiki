AI 整合開發 Skill

Claude API 開發

/claude-api

協助使用 Anthropic SDK 建立 AI 應用；涵蓋基礎 Messages API 呼叫、Tool Use 工具定義與呼叫循環、Streaming 串流回應、以及 System Prompt 設計最佳實踐；適合第一次整合 Claude 或需要進階 API 功能的開發者。

Skill 資訊
指令

分類
AI 整合開發
SDK 語言
Python / TypeScript
核心功能
Tool Use, Streaming

Write, Bash

適用時機

  • 首次將 Claude 整合進自建應用，需要快速上手 SDK
  • 需要 Tool Use 讓 AI 呼叫外部函數或 API
  • 需要串流回應（Streaming）以降低使用者等待感
  • 設計多輪對話的 message history 管理機制

使用方式

  1. 描述要建立的 AI 功能
    說明你想實作的功能，例如「建立一個可呼叫天氣 API 的 AI 助理」，越具體越好。
  2. 選擇 SDK 與語言
    指定使用 Python 或 TypeScript SDK，以及是否需要 Tool Use、Streaming 等進階功能。
  3. 生成 API 呼叫程式碼
    Claude 將產出完整可執行的程式碼，包含 SDK 初始化、messages 組裝與回應解析。
  4. 測試與錯誤處理
    使用 Bash 工具執行程式，Claude 協助排查 API 錯誤並補強例外處理邏輯。

使用範例

範例：建立帶 Tool Use 的 AI 助理
/claude-api 用 Python SDK 建立一個 AI 助理， 定義一個 get_weather(city) 工具， 讓 Claude 能在對話中主動呼叫， 並以 streaming 方式輸出回應
範例：多輪對話 history 管理
/claude-api 用 TypeScript SDK 實作多輪對話， 保留 message history 並限制最多 保留 20 輪，超過時自動截斷最舊記錄

注意事項

API Key 安全管理
切勿將 ANTHROPIC_API_KEY 寫入程式碼或版本控制，應使用環境變數或 .env 檔管理，並將 .env 加入 .gitignore。

Tool Use 循環需謹慎設計
Tool Use 採用循環呼叫架構，請設定最大迭代次數避免無限循環，並對工具回傳值進行驗證以防止意外行為。
