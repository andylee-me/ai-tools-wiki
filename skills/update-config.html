系統設定 Skill

自動化行為設定

/update-config

透過修改 settings.json 的 hooks 欄位，設定「每次發生 X 事件時自動執行 Y 指令」的自動化行為；支援 PreToolUse、PostToolUse、Stop 三種事件觸發點；適合建立不需要手動啟動的背景自動化流程，讓 Claude 在指定操作前後自動執行特定腳本。

Skill 資訊
設定檔
settings.json
觸發事件
PreToolUse / PostToolUse / Stop
需要工具
Read, Edit

適用時機

  • 每次 Claude 修改檔案後自動執行測試，確保程式碼品質
  • 在每次 git push 前自動檢查程式碼格式，避免提交不符規範的程式碼
  • 對話結束後自動儲存摘要，建立工作記錄存檔
  • 過濾或記錄特定工具的呼叫行為，用於稽核或除錯

使用方式

  1. 描述要在何種事件下自動執行何種操作
    用自然語言告訴 Claude 你希望在哪個觸發點（PreToolUse、PostToolUse 或 Stop）自動執行什麼腳本或指令。例如：「每次 Edit 工具執行完畢後，自動執行 npm test」。
  2. Claude 生成對應的 hooks 設定 JSON
    Claude 會根據你的描述，產生符合格式的 hooks 設定物件，包含觸發事件名稱、匹配條件（工具名稱過濾器）以及要執行的 shell 指令。
  3. 寫入 settings.json 並驗證觸發
    Claude 使用 Edit 工具將 hooks 設定寫入 settings.json，並協助你執行一次觸發操作，驗證自動化行為是否如預期運作。

使用範例

範例：每次修改檔案後自動執行測試
/update-config 每次 Claude 使用 Edit 工具修改檔案後， 自動執行 npm test 並把結果顯示出來
範例：對話結束後自動儲存摘要
/update-config 在每次對話結束（Stop 事件）時， 自動執行 save-summary.sh 腳本 將本次對話摘要存入 logs/ 目錄

注意事項

hooks 由執行環境而非 Claude 觸發
設定完成後，hooks 中的腳本是由 Claude Code 執行環境自動呼叫，不需要也無法透過對話指令手動觸發。確保腳本具有正確的執行權限，並做好錯誤處理以避免 hook 失敗中斷工作流程。

善用工具名稱過濾器縮小觸發範圍
hooks 設定支援依工具名稱篩選，例如只在 Edit 或 Bash 工具觸發時才執行，避免每次任何工具呼叫都觸發不必要的腳本，降低效能影響。
