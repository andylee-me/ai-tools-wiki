介面設計 Skill

前端設計師

/frontend-design

生成具有獨特美感的生產級前端介面。這個 Skill 的核心原則是拒絕「AI slop」—— 不用 Inter、不用紫色漸層、不抄模板。每次生成的設計都應該有清楚的設計觀點與不可複製的視覺個性。

設計哲學

  • Bold Aesthetic Direction：每次設計前先確立明確的視覺方向（極簡主義、暴力主義、復古未來、有機自然…），絕不走中間路線。
  • Typography First：選擇獨特且有個性的字型組合，避免 Inter / Arial / Roboto 等泛用選擇。
  • 有意義的動效：動畫聚焦在高影響力時刻（頁面載入的交錯呈現），而非散落各處的小互動。
  • 空間構圖：非對稱、重疊、斜向流動、打破網格，製造視覺張力。
  • 生產等級：輸出的程式碼可直接部署，不是草稿。

使用方式

  1. 描述你的需求與情境
    說明要設計什麼（元件、頁面或應用），以及使用情境、目標受眾與任何技術限制。
  2. Claude 確立設計方向
    Skill 會根據情境選擇一個大膽、具體的設計方向，並解釋為什麼這個方向適合你的需求。
  3. 生成可執行程式碼
    輸出完整的 HTML/CSS/JS 或 React 元件，所有細節都已實作，包括 hover 效果、RWD 與動畫。
  4. 迭代調整
    若結果不符合期望，可以告訴 Claude 具體要調整的部分（色調更暗、字型更大、加入更多動效等）。

使用範例

範例 1：設計一個登入頁
/frontend-design 設計一個 SaaS 產品的登入頁， 品牌是做 AI 資料分析的， 目標受眾是企業財務部門， 要有高級感但不要冷漠
範例 2：設計工具卡片元件
/frontend-design 設計一個展示 AI 工具的卡片元件， 需要顯示工具名稱、分類標籤、描述、 定價資訊，要有強烈的設計個性， 不要用卡片圓角過大的設計

注意事項

描述愈具體，結果愈好
提供目標受眾、品牌個性、想要的情感（有趣的、嚴肅的、高端的）和任何參考風格，可以大幅提升輸出品質。

設計複雜度要匹配
極簡設計需要精確的間距與排版；極大化設計需要大量動畫與效果程式碼。告知 Claude 你偏好哪個方向，讓複雜度匹配你的需求。
