文件處理 Skill

簡報製作助手

/pptx

從文字大綱自動生成 PowerPoint 簡報（.pptx）的 Skill。可建立完整的投影片架構，包含標題頁、目錄、內容頁與結語頁；自動將段落轉換為條列要點；並提供主題配色與版面配置建議，讓簡報兼具結構清晰與視覺一致性。

Skill 資訊
指令
/pptx
分類
文件處理
輸出格式
.pptx
適用場景
商業簡報、教學投影片
需要工具
Write、Bash

適用時機

  • 需要快速將報告大綱、會議筆記或研究摘要轉化為可簡報的投影片檔案
  • 製作商業提案、產品發表或季度回顧等需要固定結構的正式簡報
  • 解析現有 .pptx 檔案，提取每頁標題與重點文字，整理成摘要文字
  • 需要批次產生多份格式一致的簡報，例如多場次課程的教學投影片
  • 想要為現有文字內容規劃投影片架構，並獲得配色與版面的建議方向

使用方式

  1. 輸入 /pptx 並提供簡報主題或大綱
    在對話中輸入 /pptx，接著描述簡報主題、目標受眾、預計投影片數量，或直接貼上你已有的章節大綱。
  2. Claude 規劃投影片架構
    Skill 會先輸出投影片架構草稿（標題頁 → 目錄 → 各內容頁 → 結語），你可以在此階段調整章節順序或要求新增刪除特定頁面。
  3. 生成 Python 腳本並執行
    確認架構後，Skill 透過 python-pptx 程式庫撰寫腳本，自動建立每張投影片的文字框、標題與條列項目，並套用指定的主題配色。
  4. 取得 .pptx 檔案並細部調整
    Claude 告知輸出檔案路徑，你可以用 PowerPoint 或 Keynote 開啟，再手動調整圖片位置、動畫效果或更換主題樣式。

使用範例

範例 1：從主題直接生成完整簡報
/pptx 製作一份「2025 年 AI 趨勢報告」簡報， 共 10 張投影片，包含標題頁、目錄、5 個趨勢章節 和結語，使用藍色系配色，儲存為 ./ai-trends.pptx
範例 2：從現有文件轉換為簡報
/pptx 讀取 ./report.md 中的內容， 依照各 ## 標題建立一張投影片， 內文自動整理為條列要點，輸出 ./slides.pptx
範例 3：解析現有簡報的內容
/pptx 讀取 ./presentation.pptx， 逐頁條列每張投影片的標題與主要文字內容， 整理成一份繁體中文摘要

注意事項

需要安裝 python-pptx 套件
本 Skill 使用 Python 的 python-pptx 程式庫操作 .pptx 格式。若環境尚未安裝，Claude 會自動執行 pip install python-pptx。請確認執行環境已有 Python 3 與 pip 可用。

圖片與動畫需手動補充
透過程式碼生成的 .pptx 以文字結構為主，投影片中的圖片插入、頁面轉場動畫、SmartArt 等視覺效果仍需在 PowerPoint 中手動設定。建議將 Skill 產出視為結構骨架，再進行視覺美化。
