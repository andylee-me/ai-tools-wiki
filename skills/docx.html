文件處理 Skill

Word 文件助手

/docx

專門處理 Microsoft Word .docx 文件的 Skill。可建立全新文件、讀取現有內容、套用標題層級與文字樣式、插入表格，以及設定段落格式。無論是撰寫正式報告、會議記錄，還是合約草稿，都能快速生成符合格式需求的 Word 文件。

指令

樣式、表格、圖片

適用時機

  • 需要輸出正式報告，且收件方要求 Word 格式（.docx）而非純文字或 PDF
  • 要為現有文字內容套用標題階層（H1-H6）、粗體、斜體等格式樣式
  • 需要在文件中插入結構化表格，例如比較表、時程表或資料摘要
  • 讀取並解析他人提供的 .docx 文件，提取其中特定段落或表格資料
  • 批次產生多份格式一致的 Word 文件，例如會議記錄範本或週報

使用方式

  1. 輸入 /docx 並說明文件需求
    在對話中輸入 /docx，接著描述你想建立或處理的文件內容，包含文件標題、章節結構、是否需要表格等。
  2. 提供內容素材或現有檔案路徑
    若是建立新文件，提供文字大綱或原始內容即可；若要讀取或修改現有文件，提供 .docx 的完整檔案路徑。
  3. Claude 生成對應的 Python 腳本並執行
    Skill 會使用 python-docx 程式庫撰寫腳本，自動套用標題、表格、段落格式等設定，並透過 Bash 工具執行腳本產生檔案。
  4. 確認輸出並調整細節
    Claude 會告知產生的 .docx 檔案路徑，你可以開啟確認後，再要求調整字型大小、頁首頁尾、段落間距等細節。

使用範例

範例 1：建立帶有標題與表格的報告
/docx 幫我建立一份 Q3 銷售報告，包含 「執行摘要」「各區域業績表格」「結論」三個章節， 儲存為 ./reports/q3-sales.docx
範例 2：讀取並摘要現有 Word 文件
/docx 讀取 ./contracts/agreement.docx 並條列出所有涉及「付款期限」的條款內容
範例 3：為純文字內容套用標題格式
/docx 將以下 Markdown 內容轉為 Word 文件， 套用對應的標題層級（# → H1，## → H2）， 輸出為 ./output/formatted.docx

注意事項

需要安裝 python-docx 套件
本 Skill 依賴 Python 的 python-docx 程式庫來操作 .docx 格式。若環境中尚未安裝，Claude 會先執行 pip install python-docx 再進行後續操作，請確保環境有 Python 3 與 pip。

複雜版面配置有限制
Word 文件中的文字方塊、藝術字、複雜多欄版面等進階排版功能，透過 python-docx 操作有其限制。若需要精細版面設計，建議先產生基本格式文件，再以 Word 軟體手動調整視覺樣式。
