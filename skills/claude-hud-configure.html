HUD 狀態列設定

/claude-hud:configure

設定 Claude Code HUD（Head-Up Display）狀態列的顯示內容與排列；可調整顯示哪些元件（模型名稱、token 用量、工具狀態、當前任務）、版面位置（頂部/底部）、以及語言與預設配置；讓你在工作時隨時掌握 Claude 的執行狀態。

Skill 資訊
指令
/claude-hud:configure
設定項目
元件 / 位置 / 語言
需要工具
Read, Edit

適用時機

  • 想在 HUD 顯示 token 用量，以便即時監控成本並控制使用量
  • 調整狀態列位置（頂部或底部）以配合個人工作習慣與終端機排版
  • 隱藏不需要的 HUD 元件，讓介面更簡潔、減少視覺干擾
  • 切換 HUD 顯示語言，或套用預設配置快速完成初始設定

使用方式

  1. 描述想要顯示的 HUD 元件與排列方式
    用自然語言告訴 Claude 你希望 HUD 顯示哪些資訊、放在螢幕的哪個位置，例如：「我想在底部顯示 token 用量和當前工具狀態，不需要顯示模型名稱」。
  2. Claude 生成對應的 HUD 設定
    Claude 會根據你的需求，產生符合 HUD 設定格式的設定物件，包含要啟用的元件清單、位置參數、語言選項，以及是否套用預設配置（preset）。進階手動覆寫的設定將被保留不受影響。
  3. 套用設定並確認顯示效果
    Claude 使用 Edit 工具將 HUD 設定寫入對應的設定檔。套用後，HUD 狀態列會即時或在下次啟動時更新顯示，請確認元件排列與內容符合預期。

使用範例

範例：顯示 token 用量並移至底部
/claude-hud:configure 把 HUD 移到螢幕底部， 顯示 token 用量和當前任務， 不需要顯示模型名稱
範例：套用簡潔預設配置
/claude-hud:configure 我想要最簡潔的 HUD 設定， 只顯示工具狀態，其他元件都隱藏

注意事項

進階手動覆寫設定會被保留
使用此 Skill 調整 HUD 設定時，只有 Skill 管理的選項（元件、位置、語言、預設配置）會被修改。你在設定檔中手動加入的進階覆寫項目不會被清除，能安全地與 Skill 設定共存。

先用 /claude-hud:setup 完成初始安裝
若你尚未安裝 claude-hud，請先執行 /claude-hud:setup 完成初始設定與安裝流程，再使用 /claude-hud:configure 調整顯示選項。直接執行 configure 而未安裝可能會找不到設定檔位置。
