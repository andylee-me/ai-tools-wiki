文件處理 Skill

試算表助手

/xlsx

專門讀取、分析並輸出 Excel 與 CSV 資料的 Skill。可自動進行欄位整理、資料清洗、公式生成（SUM、VLOOKUP、PIVOT 等），以及產生摘要統計。適合在資料分析前置處理階段快速理解資料結構，或將散亂資料整理為乾淨的試算表格式。

指令
/xlsx
分類

.xlsx / .csv
核心功能
清洗、公式、樞紐分析

Read、Bash

適用時機

  • 需要快速了解一份陌生 Excel 檔案的欄位結構、資料筆數與基本統計
  • 資料中存在空值、重複列、格式不一致等問題，需要進行清洗與標準化
  • 要為試算表新增公式欄位，例如計算總和、百分比、VLOOKUP 對照或條件式統計
  • 需要將多張工作表或多個 CSV 檔案合併為一份整合資料集
  • 作為資料分析前置步驟，整理資料後輸出乾淨的 .csv 供後續工具使用

使用方式

  1. 輸入 /xlsx 並提供檔案路徑與需求
    在對話中輸入 /xlsx，接著提供 .xlsx 或 .csv 的檔案路徑，並說明你想要做的操作（讀取、清洗、新增公式、合併或輸出）。
  2. Claude 讀取並分析資料結構
    Skill 使用 pandas 或 openpyxl 讀取檔案，回報欄位名稱、資料類型、筆數、缺失值等基本資訊，讓你確認資料狀況後再進行後續操作。
  3. 執行指定的資料處理操作
    根據你的需求，Skill 會撰寫並執行 Python 腳本，完成清洗（去重、填補空值）、公式計算、樞紐分析或資料合併等任務。
  4. 輸出整理後的檔案
    處理完成後，Claude 將結果儲存為 .xlsx 或 .csv，並告知輸出路徑。你也可以要求同時輸出摘要統計報告。

使用範例

範例 1：讀取並清洗資料
/xlsx 讀取 ./data/sales_2024.xlsx， 移除重複列、填補空白的「地區」欄位為「未分類」， 輸出清洗後的結果為 ./data/sales_clean.xlsx
範例 2：新增計算公式欄位
/xlsx 在 ./orders.csv 中新增「毛利率」欄位， 計算公式為 (售價 - 成本) / 售價， 並新增「是否達標」欄位（毛利率 >= 0.3 為 TRUE）
範例 3：合併多個 CSV 並做樞紐分析
/xlsx 合併 ./q1.csv、./q2.csv、./q3.csv， 依「產品類別」和「月份」做樞紐分析， 統計各類別每月銷售總額，輸出 ./pivot.xlsx

注意事項

需要安裝 pandas 與 openpyxl
本 Skill 依賴 pandas 和 openpyxl 程式庫處理試算表資料。若環境尚未安裝，Claude 會先執行 pip install pandas openpyxl。大型檔案（超過 10 萬列）處理時間可能較長，建議先測試小批量資料。

編碼問題處理
若 CSV 檔案包含中文且出現亂碼，請在需求中告知原始編碼格式（如 Big5 或 UTF-8-BOM）。Skill 會在讀取時指定正確的 encoding 參數，避免中文字元損毀。
