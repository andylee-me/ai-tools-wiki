自動化流程 Skill

網路存取工具

/web-access

所有需要聯網操作的統一入口；整合搜尋、網頁抓取、特定頁面解析等功能；支援在登入後的操作模式下存取需要驗證的頁面；適合蒐集即時資訊、比較競爭對手、或批次抓取公開資料。

Skill 資訊
指令
/web-access
分類
自動化流程
功能模式
搜尋/抓取/解析
支援格式
HTML, JSON, RSS
需要工具
WebSearch, WebFetch

適用時機

  • 需要查詢 Claude 知識截止日後的最新資訊
  • 從指定網頁提取結構化資料
  • 比較多個網站的資訊並彙整
  • 自動化蒐集公開 API 或網頁資料

使用方式

  1. 描述要存取的網路資源或搜尋目標
    輸入 /web-access 並說明你需要搜尋的關鍵字、要抓取的頁面網址，或想從哪個網站提取哪種資料。
  2. Claude 選擇搜尋或直接抓取並解析內容
    若提供了明確網址，Claude 使用 WebFetch 直接抓取頁面；若提供的是搜尋需求，則使用 WebSearch 找到相關頁面後再進行解析。
  3. 將結果整理成可用格式回傳
    解析完成後，Claude 以結構化方式整理結果，可輸出為純文字摘要、JSON 資料或 Markdown 表格，方便後續使用。

使用範例

範例 1：搜尋最新資訊
/web-access 搜尋「Claude 3.5 Sonnet 最新更新」 並整理出最重要的 3 個改動
範例 2：抓取特定頁面資料
/web-access 抓取 https://example.com/pricing 並將各方案的價格整理成表格
範例 3：批次比較多個來源
/web-access 搜尋前 3 個雲端儲存服務的免費方案， 比較容量上限與功能限制

注意事項

尊重網站使用條款
使用本 Skill 抓取網頁時，請確認目標網站允許自動化存取，避免對伺服器造成過大負載或違反使用條款。

搭配 /loop 實現定期抓取
若需要每隔一段時間重新抓取同一個頁面以追蹤變化，可搭配 /loop 設定循環間隔，或使用 /schedule 建立持久排程。
