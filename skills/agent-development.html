Agent 開發指南

/agent-development

引導建立自訂 Claude Code Agent（子流程）；協助撰寫 Agent 的 frontmatter（description、model、tools）、定義工具清單與使用限制、撰寫清楚的觸發條件描述讓主 Claude 知道何時呼叫；輸出可直接部署的 Agent markdown 檔案。

Skill 資訊
指令
/agent-development
分類
AI 整合開發
輸出格式
.md agent 定義檔
關鍵欄位
frontmatter, tools
需要工具
Write

適用時機

  • 需要專門處理特定任務的子流程，與主流程分離管理
  • 想並行執行多個獨立任務以提升整體效率
  • 需要隔離某些高風險操作，讓子流程在受限環境執行
  • 建立可複用的專業 Agent 庫，供團隊成員共用

使用方式

  1. 描述 Agent 的職責與使用時機
    說明這個 Agent 負責什麼任務、何時應該被呼叫，以及需要哪些輸入資訊。
  2. 定義工具清單與限制
    指定 Agent 可使用的工具集合，以及明確禁止的操作，確保子流程在安全邊界內執行。
  3. 生成 frontmatter 與說明文件
    Claude 產出完整的 Agent markdown 檔，包含 YAML frontmatter 與清楚的職責說明段落。
  4. 部署至 .claude/agents/ 目錄
    將生成的 .md 檔存入專案的 .claude/agents/ 目錄，主 Claude 即可識別並在適當時機呼叫它。

使用範例

範例：建立程式碼審查 Agent
/agent-development 建立一個專門做程式碼審查的 Agent， 只能使用 Read 和 Grep 工具， 不可修改任何檔案， 在使用者提交 PR 前自動觸發
範例：建立測試執行 Agent
/agent-development 建立測試執行 Agent，使用 Bash 工具， 負責執行 pytest 並回報失敗案例， 當主流程修改 Python 檔案後呼叫

注意事項

description 欄位決定呼叫時機
frontmatter 中的 description 是主 Claude 判斷何時委派任務的依據，請用清晰的一句話描述觸發情境，避免過於模糊的說明。

工具清單越精簡越好
只賦予 Agent 完成任務所需的最少工具集，過多工具會增加 Agent 誤操作的機會，也讓主 Claude 更難預測子流程行為。
