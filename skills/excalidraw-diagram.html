Excalidraw 圖表

/excalidraw-diagram

根據描述生成 Excalidraw 相容的 JSON 格式圖表，可視覺化系統架構、工作流程、 概念關係圖與序列圖。輸出的 JSON 可直接匯入 Excalidraw 使用， 保留手繪風格的流程與連線，讓技術溝通更直覺清晰。

適用時機

  • 需要快速產出系統架構圖，讓團隊對技術設計達成共識
  • 規劃使用者操作流程（User Flow），以視覺化方式呈現步驟與分支
  • 整理概念之間的關聯，製作心智圖或概念圖
  • 繪製 API 或服務之間的序列圖，說明請求與回應的時序關係
  • 需要可編輯的手繪風格圖表，而非嚴格規格的 UML 圖
  • 將文字說明的架構快速轉換為可視覺化圖形與同事分享討論

使用方式

  1. 描述要畫的圖表內容
    說明圖表的類型（流程圖、架構圖、心智圖等）以及包含的主要節點與關係，描述越清楚，生成結果越準確。
  2. Claude 生成 Excalidraw JSON
    Skill 會根據描述建構符合 Excalidraw 格式的 JSON，包含每個元素的座標、連線關係、文字標籤與手繪風格參數。
  3. 將 JSON 儲存為 .excalidraw 檔
    Claude 會使用 Write 工具將 JSON 儲存到指定路徑，副檔名為 .excalidraw，或你可以手動複製貼上內容。
  4. 匯入 Excalidraw 開啟編輯
    在 Excalidraw 應用程式（桌面版或 Web 版）中選擇「Open」並選取 .excalidraw 檔，圖表即可載入，之後可自由拖拉調整。

使用範例

範例 1：系統架構圖
/excalidraw-diagram 畫一個微服務架構圖，包含： API Gateway → Auth Service、 User Service、Order Service， 三個服務都連接到同一個 PostgreSQL
範例 2：使用者流程圖
/excalidraw-diagram 畫使用者登入流程：進入首頁 → 點擊登入 → 填寫表單 → 驗證成功 （失敗則顯示錯誤並重試）→ 進入後台
範例 3：概念心智圖
/excalidraw-diagram 畫一個以「CI/CD Pipeline」為中心 的心智圖，分支包含： Build、Test、Deploy、Monitor

注意事項

節點數量影響生成品質
圖表節點建議控制在 20 個以內，節點過多時自動排版可能導致元素重疊。複雜架構建議拆成多張圖分別生成，再匯入同一個 Excalidraw 畫布整合。

生成後可自由手動調整
Excalidraw 的優勢在於可編輯性。Claude 生成的圖表是起點，不必追求一次到位，匯入後可以自由拖拉節點位置、修改文字、調整連線路徑，讓圖表更符合你的需求。
