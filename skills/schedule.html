自動化流程 Skill

定時排程任務

/schedule

建立持久化的定時排程，使用 Cron 語法設定自動化任務的執行頻率；支援建立、列出、更新與刪除排程；任務以遠端 Agent 形式執行，不需要維持本地對話；適合定期報告生成、自動備份或週期性資料同步。

適用時機

  • 每天定時生成報告或摘要
  • 定期備份重要檔案或資料
  • 週期性呼叫 API 並記錄結果
  • 自動化日常重複性的維護任務

使用方式

  1. 描述要定期執行的任務內容
    輸入 /schedule 並說明想要自動化的任務，例如「每天早上整理昨日的 git commit 紀錄並生成摘要」。
  2. 指定執行頻率（如「每天早上 9 點」）
    用自然語言描述執行頻率，Claude 會自動將其轉換為對應的 Cron 表達式。
  3. 生成 Cron 表達式並建立排程
    Claude 產出 Cron 表達式後，呼叫 CronCreate 工具將排程寫入系統，任務將在背景以遠端 Agent 執行。
  4. 確認排程列表與下次執行時間
    建立完成後，Claude 顯示所有現有排程及下次觸發時間，確認設定無誤。

使用範例

範例 1：每天早上 9 點生成報告
/schedule 每天早上 9 點讀取 ./data/metrics.json 並生成日報摘要寫入 ./reports/ 目錄
範例 2：列出所有現有排程
/schedule 列出目前所有已建立的排程 並顯示每個排程的下次執行時間
範例 3：刪除指定排程
/schedule 刪除名稱為 "daily-report" 的排程

注意事項

任務以遠端 Agent 執行
排程觸發時會啟動一個獨立的遠端 Agent 執行任務，本地對話無需保持開啟，確保電腦關機或離線時任務仍能正常執行。

短期輪詢改用 /loop
若只需在當前對話中反覆執行數次的輕量任務，使用 /loop 更為簡便；/schedule 適合需要長期持久執行的自動化排程。
