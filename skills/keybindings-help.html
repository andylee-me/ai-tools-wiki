快捷鍵設定

/keybindings-help

協助自訂 Claude Code 的鍵盤快捷鍵；說明如何修改 keybindings.json 以重新綁定現有快捷鍵、新增 Chord 組合鍵（兩鍵序列觸發）、或停用不常用的預設按鍵；適合想提升操作效率、習慣自訂鍵位的進階使用者。

Skill 資訊
設定檔
keybindings.json
功能
重新綁定 / Chord 序列鍵
需要工具
Read, Edit

適用時機

  • 現有快捷鍵與其他工具衝突，需要更換為不同的按鍵組合
  • 想新增一個快速觸發常用 Skill 的按鍵，減少重複輸入指令的時間
  • 設定 Vim 或 Emacs 風格的鍵位習慣，讓操作符合個人慣性
  • 為特定工作流程建立自訂鍵盤捷徑，提升多工操作效率

使用方式

  1. 描述要綁定的操作與偏好的按鍵組合
    用自然語言說明你想綁定的功能與目標按鍵，例如：「我想用 Ctrl+K Ctrl+S 快速執行 /simplify 指令」或「幫我把送出訊息的鍵從 Enter 改成 Ctrl+Enter」。
  2. Claude 生成 keybindings.json 設定
    Claude 會根據你的需求，產生符合格式的按鍵綁定設定物件，包含 key 序列、command 名稱，以及選填的 when 條件。Chord 組合鍵會以空格分隔兩個按鍵序列。
  3. 寫入設定檔並重啟生效
    Claude 使用 Edit 工具將新設定寫入 keybindings.json。設定完成後，重啟 Claude Code 讓新的快捷鍵生效，接著可以實際按鍵測試是否正常觸發。

使用範例

範例：新增 Chord 組合鍵觸發 Skill
/keybindings-help 我想用 Ctrl+K 再按 R 這個 Chord 組合鍵 快速執行 /code-reviewer 指令
範例：重新綁定衝突的快捷鍵
/keybindings-help Ctrl+P 快捷鍵和我的終端機設定衝突， 請幫我改成 Ctrl+Shift+P

注意事項

重啟後才會生效
修改 keybindings.json 後，必須完整重啟 Claude Code 才能載入新設定。熱重載不支援快捷鍵設定，請確保重啟前已儲存好所有進行中的工作。

避免與系統快捷鍵重疊
設定前先確認目標按鍵組合未被作業系統或終端機佔用，否則 Claude Code 的快捷鍵可能無法正常攔截。若遇到按鍵無反應，請優先排查系統層級的快捷鍵衝突。
