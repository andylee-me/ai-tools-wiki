文件處理 Skill

PDF 閱讀助手

/pdf

處理所有 PDF 相關任務的專用 Skill。無論是讀取內容、提取表格、合併多個 PDF， 或是從大型報告中找出關鍵資訊，只要輸入 /pdf 指令，Claude 就會以最佳方式處理。

Skill 資訊
指令
/pdf
分類
文件處理
輸入格式
.pdf 檔案路徑
輸出格式
文字 / Markdown
需要工具
Read, Bash, Write

適用時機

  • 需要讀取 PDF 文件的內容並摘要重點
  • 要從研究報告、合約或手冊中提取特定資訊
  • 需要將多個 PDF 合併為一份文件
  • 要從 PDF 表格中提取資料並轉為結構化格式
  • 需要比對兩份 PDF 的差異內容
  • 大型 PDF（超過 10 頁）需要分頁讀取時

使用方式

  1. 輸入 /pdf 指令並描述需求
    在對話中輸入 /pdf，然後告訴 Claude 你的 PDF 路徑以及想要做什麼（讀取、提取、合併等）。
  2. 提供 PDF 檔案路徑
    告知 PDF 的檔案路徑，例如 /Users/xxx/documents/report.pdf 或相對路徑 ./docs/report.pdf。
  3. Claude 自動選擇最佳處理方式
    Skill 會根據 PDF 大小與需求，決定是直接讀取全文、分頁讀取還是針對特定頁碼範圍操作。
  4. 取得處理結果
    Claude 以 Markdown 格式回傳摘要、提取內容或操作結果，可進一步要求儲存為新檔案。

使用範例

範例 1：讀取並摘要 PDF
/pdf 讀取 ./report.pdf 並用繁體中文條列 出前 5 個最重要的結論
範例 2：提取特定頁碼
/pdf 從 ./contract.pdf 的第 10-15 頁 提取所有關於付款條件的條款
範例 3：合併多份 PDF
/pdf 合併 ./chapter1.pdf、./chapter2.pdf 和 ./chapter3.pdf 為 ./book.pdf

注意事項

大型 PDF 分頁讀取
若 PDF 超過 10 頁，建議在指令中指定頁碼範圍（如「第 5-10 頁」），避免一次讀取過多內容造成超出 Context 上限。

掃描版 PDF 限制
掃描產生的圖片型 PDF 無法直接提取文字，需要搭配 OCR 工具預處理後才能使用本 Skill。
