對話交接文件

/handoff

將當前對話的所有重要脈絡壓縮成結構化的交接文件（markdown 格式）；包含任務目標、已完成項目、待辦清單、關鍵決策與注意事項；讓另一個 Claude Agent 或新對話可以無縫接手繼續執行，不遺漏背景資訊。

適用時機

  • 對話即將達到 context 上限
  • 需要將任務交給另一個專門的 Agent 處理
  • 想在新對話中繼續複雜的長期任務
  • 記錄目前工作狀態以便日後恢復

使用方式

  1. 在對話即將結束或交接前執行
    當感覺對話快達到 context 上限，或決定要將任務移交時，輸入 /handoff 啟動交接文件生成流程。
  2. Claude 自動整理對話脈絡生成交接文件
    Claude 掃描整個對話歷程，提取任務目標、已完成的步驟、尚未完成的待辦事項、重要決策與注意事項，組成結構化的 Markdown 文件。
  3. 在新對話中將文件貼給 Claude 以無縫接手
    開啟新對話或交給其他 Agent 時，將交接文件的內容貼入，新的 Claude 實例即可立即掌握完整背景，繼續執行任務。

使用範例

範例 1：生成並儲存交接文件
/handoff 生成交接文件並儲存至 ./handoff-2024-01-15.md
範例 2：交接給特定 Agent
/handoff 為 /diagnose Agent 準備交接文件， 重點標記尚未解決的 Bug 清單

注意事項

越早執行越完整
建議在對話仍有足夠 context 空間時執行 /handoff，避免在對話快結束時才執行導致部分歷史資訊無法被讀取，影響交接文件的完整性。

可補充自定義要點
執行時可在指令後附加特殊說明，例如「特別注意權限設定的部分」，Claude 會在交接文件中強調這些重點，確保接手方不會遺漏關鍵資訊。
