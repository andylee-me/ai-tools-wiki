MCP 伺服器整合

/mcp-integration

協助在 Claude Code 的 Plugin 或設定中接入 Model Context Protocol 伺服器；支援設定 stdio 與 SSE 兩種連線模式；幫助定義 MCP server 的工具清單、資源路徑與存取權限；適合需要讓 Claude 存取外部 API 或本地工具的情境。

適用時機

  • 讓 Claude 能直接存取本地資料庫或檔案系統
  • 連接第三方 API（如 GitHub、Slack 等）供 Claude 操作
  • 共用自訂工具給整個開發團隊統一使用
  • 建立公司內部 MCP 工具伺服器以擴充 Claude 能力

使用方式

  1. 描述要連結的外部服務
    說明你想讓 Claude 存取哪些外部服務或本地工具，以及需要哪些操作權限。
  2. 生成 MCP server 設定
    Claude 將產出 MCP server 的完整設定，包括連線模式、工具清單定義與資源路徑。
  3. 寫入 settings.json
    將生成的設定加入 Claude Code 的 settings.json 或 .mcp.json，套用 MCP 伺服器連線。
  4. 驗證工具可用性
    重啟 Claude Code 後，確認 MCP 工具出現在可用工具清單中，並執行簡單指令測試連線。

使用範例

範例：整合本地檔案系統 MCP
/mcp-integration 幫我設定一個 stdio 模式的 MCP server， 讓 Claude 能讀寫 ~/Documents/projects 目錄下的所有檔案，並限制不可刪除
範例：連接 GitHub API
/mcp-integration 設定 SSE 模式 MCP 連接 GitHub， 需要 list_repos、create_issue、 read_file 三個工具，使用 PAT 驗證

注意事項

存取權限最小化原則
設定 MCP server 時，僅開放 Claude 實際需要的工具與資源路徑，避免授予過大的存取範圍，降低誤操作風險。

stdio 與 SSE 的選擇
本地工具建議使用 stdio 模式，部署於遠端或需多人共用的服務則選擇 SSE 模式，前者延遲更低，後者更易於集中管理。
