Postrboard 設計

/postrboard

應用 Postrboard 的「Quiet CSS」設計哲學——克制的視覺風格、以內容為主的排版、拒絕過度裝飾。 生成乾淨、可維護的 HTML/CSS，適合內容導向的文章頁、文件站與輕量工具界面， 讓設計退到背景，讓內容站到前面。

適用場景
內容導向介面

適用時機

  • 設計部落格、技術文章頁或文件站，希望排版清晰不干擾閱讀
  • 製作輕量的後台工具或內部看板，不需要華麗視覺效果
  • 發現現有介面過度裝飾、動畫太多，需要重新收斂風格
  • 需要高可維護性的 CSS，避免日後改版時的樣式衝突
  • 想要讓設計服務於內容，而非以設計本身為目的的場景
  • 快速搭建 MVP 或原型，需要立刻可用且不失品味的基礎樣式

使用方式

  1. 說明頁面類型與內容結構
    描述要設計的頁面（文章頁、工具介面、文件站首頁等），以及主要的內容區塊（標題、正文、側欄、表格等）。
  2. Claude 套用 Quiet CSS 原則
    Skill 會以克制為基準：選用可讀性高的字型組合、充足的行距與留白、低飽和度色彩，拒絕陰影堆疊、漸層背景與無意義的動畫。
  3. 取得完整 HTML/CSS 輸出
    Claude 生成可立即使用的完整 HTML 與 CSS，變數清晰定義在 :root，便於後續自訂品牌色彩與字型。
  4. 根據實際內容微調
    將真實內容替換進去後，可告知 Claude 哪些比例需要調整，例如「行距稍微再寬一點」或「標題層級要更明顯」。

使用範例

範例 1：技術文章閱讀頁
/postrboard 設計一個技術部落格文章頁， 需要：大標題、發布日期、正文（含 程式碼區塊與圖片）、相關文章列表， 要乾淨、易讀、不要花俏動效
範例 2：輕量後台工具介面
/postrboard 設計一個內部報表工具的 UI， 左側導覽、右側主內容區含表格， 功能優先，視覺克制，不用卡片陰影
範例 3：文件站首頁
/postrboard 設計一個開源專案的文件站首頁， 包含導覽列、Hero 區、功能說明列表、 快速入門步驟，Quiet 風格

注意事項

Quiet 不等於無個性
Quiet CSS 的克制是有觀點的克制，不是放棄品味。好的 Quiet 設計在字型選擇、行距比例、留白節奏上仍然有強烈的設計判斷，只是把注意力導向內容，而非裝飾本身。

與 /frontend-design 的差異
/frontend-design 追求大膽、獨特的視覺方向，適合行銷頁、展示頁或需要強烈品牌印象的場景。/postrboard 則適合以內容消費為主的頁面，兩者目標不同，依使用場景選擇。
