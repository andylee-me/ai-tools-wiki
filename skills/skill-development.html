自訂擴充 Skill

Skill 開發指南

/skill-development

引導從零建立一個可在 Claude Code 中呼叫的自訂 Skill；協助撰寫 Skill 的 frontmatter（description、when_to_use、args）、主體 prompt 內容、以及讓 Claude 知道何時主動呼叫的觸發描述；輸出可直接部署的 .md Skill 定義檔。

Skill 資訊
指令
/skill-development
分類
自訂擴充
輸出格式
.md Skill 定義檔
關鍵欄位
frontmatter, when_to_use
部署位置
.claude/skills/

適用時機

  • 有一個常用的操作模式想要指令化，讓 Claude 一鍵執行固定流程
  • 需要給 Claude 一組特定的行為規範，使其在特定情境下遵循客製邏輯
  • 想建立團隊共用的 Skill 庫，統一工作方式與輸出品質
  • 已有 prompt 範本想包裝成可複用的 Skill，方便日後維護與分享

使用方式

  1. 描述 Skill 的功能與觸發場景
    告訴 Claude 這個 Skill 要做什麼、在什麼情況下應該被呼叫，以及有哪些可選參數（args）。
  2. Claude 生成 frontmatter 草稿
    Claude 會自動產生包含 description、when_to_use、args 等欄位的 frontmatter，可依需求調整內容。
  3. 撰寫 Skill 主體 prompt
    補充 Skill 執行時的詳細指令說明，包括行為規範、輸出格式要求與範例，讓 Claude 有足夠的脈絡執行任務。
  4. 寫入 .claude/skills/ 並測試
    將生成的 .md 檔案放置於 .claude/skills/ 目錄，重新啟動 Claude Code 後即可使用斜線指令呼叫新 Skill。

使用範例

範例：建立程式碼審查 Skill
/skill-development 我想建立一個 Skill，當使用者輸入 /code-review 時， 自動審查當前目錄的 Git diff，並輸出 安全性問題、效能問題與程式碼風格建議三個區塊。
範例：建立帶參數的 Skill
/skill-development 建立 /translate 指令，接受 lang 參數（預設 en）， 將使用者輸入的文字翻譯至指定語言， 並保留原文的 Markdown 格式。

注意事項

when_to_use 是觸發關鍵
frontmatter 中的 when_to_use 欄位決定 Claude 是否會主動推薦使用這個 Skill。描述越具體、場景越明確，Claude 自動選用的準確率越高。

部署後需重新載入
將 .md 檔案放入 .claude/skills/ 後，需要重新啟動或重新載入 Claude Code 工作區，新 Skill 才會出現在可用指令清單中。
