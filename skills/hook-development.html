Hook 開發指南

/hook-development

協助建立 Claude Code 的 Hook 腳本；支援三種 Hook 類型：PreToolUse（工具呼叫前驗證）、PostToolUse（工具呼叫後處理）、Stop（對話結束時自動執行）；Hook 以 shell script 或任意可執行指令實作；可用於自動格式化、安全驗證、自動提交等場景。

Skill 資訊
指令

實作語言
Shell / 任意可執行

settings.json hooks 區段

適用時機

  • 每次存檔後自動執行 lint 或格式化，確保程式碼風格一致
  • 防止 Claude 刪除特定目錄或檔案，加入操作前的安全驗證
  • 在對話結束時自動 git commit，記錄每次工作階段的變更
  • 記錄所有工具呼叫行為到 log 檔，方便事後稽核與除錯

使用方式

  1. 描述要在何時自動執行什麼
    用自然語言說明觸發時機（工具呼叫前/後/對話結束時）以及要自動執行的具體行為。
  2. 決定 Hook 類型（Pre / Post / Stop）
    Claude 會根據描述建議合適的 Hook 類型：PreToolUse 用於驗證與攔截、PostToolUse 用於後處理、Stop 用於對話結束後的收尾動作。
  3. 生成 Hook 腳本
    Claude 生成對應的 shell script 或可執行指令，包含必要的錯誤處理與輸出格式，使腳本能正確回傳狀態碼給 Claude Code。
  4. 寫入 settings.json 並測試
    將 Hook 設定加入 settings.json 的 hooks 區段，指定觸發條件與腳本路徑，重新啟動後驗證 Hook 是否如預期執行。

使用範例

範例：自動格式化 PostToolUse Hook
/hook-development 每次 Claude 寫入 .py 檔案後，自動執行 black 格式化與 ruff lint 檢查， 若有錯誤則輸出訊息讓 Claude 知道需要修正。
範例：Stop Hook 自動提交
/hook-development 在每次對話結束時，若工作目錄有未提交的變更， 自動執行 git add . 和 git commit， commit message 使用當天日期與時間。

注意事項

腳本需具備可執行權限
Hook 腳本檔案必須設定可執行權限（chmod +x），否則 Claude Code 在呼叫時會因權限不足而靜默失敗，建議在部署後立即執行手動測試確認。

PreToolUse 返回碼決定是否繼續
PreToolUse Hook 的腳本若返回非零狀態碼，Claude Code 會中止對應的工具呼叫。設計安全驗證 Hook 時，請確保只在真正需要攔截的情況才返回非零值。
