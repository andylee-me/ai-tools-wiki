Claude API 開發 使用 Claude API 或 Anthropic SDK 建立 AI 應用，含 tool use、streaming 等進階功能
/mcp-integration
MCP 伺服器整合 在 Plugin 中設定 Model Context Protocol 伺服器，連結外部服務並擴充工具能力
/agent-development
Agent 開發指南 建立自訂子 Agent，定義 frontmatter、工具清單與使用時機範例
/codex:rescue
Codex 任務委派 當 Claude Code 卡關時，將複雜任務委派給 Codex 子流程進行深度調查

自動化流程

循環任務、排程與對話交接工具 4 SKILLS
/loop
循環任務執行 以指定間隔循環執行某個指令或 Skill，適合定期輪詢狀態或建立監控任務
/schedule
定時排程任務 建立、更新、列出定期執行的遠端 Agent 任務，以 Cron 語法設定自動化排程
/handoff
對話交接文件 將當前對話壓縮成結構化交接文件，讓另一個 Agent 可以無縫接手繼續執行任務
/web-access
網路存取工具 所有聯網操作的統一入口，含搜尋、網頁抓取、登入後操作與社群媒體內容擷取

自訂擴充

/skill-development
Skill 開發指南 建立自訂 Skill 的完整流程，含 frontmatter 設計與觸發條件描述最佳實踐
/hook-development
Hook 開發指南 建立 PreToolUse / PostToolUse / Stop Hook，在工具呼叫前後加入驗證或自動化邏輯
/command-development
Slash Command 開發 建立自訂 Slash Command，定義指令參數、frontmatter 格式與組織管理多個指令
/plugin-structure
Plugin 架構指南 建立完整 Plugin 架構，了解 plugin.json 設定、目錄組織與各元件職責分工
