Midjourney

圖像生成

頂尖的文字生圖 AI，以獨特的藝術美感與細膩風格輸出聞名業界。透過 Discord Bot 或 Web 介面，輸入文字描述即可生成令人驚艷的精緻圖像。

開發商 · Midjourney, Inc.
發布 · 2022
版本 · V6.1
平台 · Discord / Web

核心功能

  • 01
    文字生成圖像（Text-to-Image）
    輸入自然語言描述，Midjourney 自動生成 4 張高解析度圖像。擅長藝術風格、概念設計與細節豐富的場景渲染。
  • 02
    圖像細化（Upscale）
    選擇初始生成的圖像後，可進行高解析度放大，保留細節並強化紋理品質，適合用於印刷或大尺寸輸出。
  • 03
    變體生成（Variation）
    針對喜愛的圖像生成多種風格變體，保留主要元素的同時調整細節、色調與構圖，快速探索設計可能性。
  • 04
    風格參數調整（--style、--stylize）
    透過 --stylize 參數控制藝術化程度，--style 參數選擇特定風格基調，讓生成結果更貼近設計需求。
  • 05
    Describe 功能（以圖反推 Prompt）
    上傳任意圖像，Midjourney 自動分析並生成可重現該圖風格的 Prompt，幫助使用者學習有效的描述語法。
  • 06
    Remix 模式
    在生成變體時可修改 Prompt，結合原始圖像的構圖與新描述的風格，創造獨特的混合視覺效果。

常用 Prompt 參數速查

  • --ar
    長寬比（Aspect Ratio）
    例：--ar 16:9（橫版）、--ar 1:1（方形）、--ar 2:3（直版）
  • --v
    模型版本（Version）
    例：--v 6.1 為最新版，細節與真實感最佳；--niji 6 為動漫風格專用版本。
  • --s
    藝術化程度（Stylize）
    數值範圍 0–1000，預設 100。數值越高藝術感越強烈，越低則越忠實於文字描述。
  • --no
    排除元素（Negative Prompt）
    例：--no text, watermark, blurry，告知 Midjourney 不要包含指定元素。

優缺點分析

優點
  • 藝術美感輸出業界頂尖，風格一致性高
  • 支援大量 Prompt 參數，可精細調控
  • Describe 功能幫助快速學習提示語法
  • 社群活躍，有大量創意範例可參考
  • V6 版本細節與真實感大幅提升
缺點
  • 無免費版，需付費訂閱才能使用
  • 人物細節（尤其手部）仍有不穩定情況
  • 操作介面以 Discord 為主，學習曲線較高
  • 生成結果隨機性強，不易精確控制構圖

實際應用場景

  • 01
    概念設計與視覺發想
    設計師在專案初期可用 Midjourney 快速生成多種概念草案，作為視覺方向討論的基礎，大幅縮短手稿發想時間。
  • 02
    社群媒體視覺素材
    品牌行銷人員可輸入風格指引，批量生成符合品牌調性的貼文圖像、封面設計，快速滿足多平台素材需求。
  • 03
    小說 / 遊戲角色概念圖
    創作者可輸入詳細的角色描述（種族、服裝、風格），讓 Midjourney 生成角色設定圖，作為後續繪製或 3D 建模的參考。
  • 04
    室內設計情境模擬
    設計師輸入空間風格、色調與傢俱偏好，生成逼真的室內設計情境圖，快速向客戶展示設計方向，省去傳統 3D 渲染時間。
